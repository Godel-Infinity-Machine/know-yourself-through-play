# Privacy and safety

This is a local, single-person gaming companion. It is not medical care, psychological counselling, assessment, diagnosis or personality classification. Personal interpretations are hypotheses the user can correct. The exact first-use notice is in `src/policy.ts`; the agent is instructed to display it at the first interaction in each chat. Because DSH owns output rendering, notice display and scientific response quality must still be checked with the actual model.

Steam import is a local CLI action with explicit `--consent-local-storage` and `--consent-model-context` acknowledgements. The user supplies a SteamID64 and the country where that machine stores the data. The key comes only from local `STEAM_API_KEY`. No passwords, cookies, sign-in interception, privacy bypass, general scraping, API key in a prompt, or public library upload is used. Consent is not Steam authentication or proof of account ownership; this is a trusted single-user local tool. It does not implement OpenID or a hosted multiuser service.

The official [IPlayerService interface](https://partner.steamgames.com/doc/webapi/IPlayerService) is used for `GetOwnedGames`. Public/otherwise API-visible game details are required. Private, malformed or unavailable responses fail without changing memory; manual preferences remain available. A recent library snapshot is reused for 15 minutes unless explicitly refreshed. At most two attempts share an 8-second budget; HTTP 429 and privacy/auth errors are not retried. A single request is capped at 8 MB / 20,000 entries. This app has no scheduler or bulk-import path. Valve's published terms set a 100,000-request/day ceiling, not a recommended operating rate. [Steam Web API Terms](https://steamcommunity.com/dev/apiterms) were checked on 2026-11-25; review them again before operating a service.

Stored Steam fields: app ID/name, ownership, total minutes, optional recent minutes, optional last-played timestamp and fetch time. Missing recency stays unknown. A SHA-256 account identifier is kept locally to prevent cache reuse across different Steam accounts; this is still linkable personal data, not anonymization. The original SteamID and API key are not stored. The hash is omitted from model context. Steam data is provided as is, without warranty; this project is unaffiliated with Valve. Storage is on the user's machine in the user-declared country. You must not enter a false country or assume a country from language. The local model/DSH deployment may have additional storage locations; review its provider policies.

Taste Memory contains exact relevant human quotations with source IDs, observed behavior, and tentative/confirmed/rejected/revised hypotheses with evidence and conditions. Memory defaults to `~/.dsh/know-yourself-through-play/taste-memory.json`, or the explicit configured local path. It is not encrypted. Files are created with owner-only POSIX mode; Windows protection follows the account/folder ACL and is not configured by this plugin. Exclusive lock plus atomic rename protect writes; stale locks require checking that no writer runs before manual removal. Invalid files fail closed and are preserved.

Memory and selected library observations are sent into DSH context. A remote model may receive them. DSH chat logs, tool results and the model provider may retain copies separately. This plugin has no default telemetry and performs no network requests except the user-triggered Steam import; model/web calls are owned by DSH. It does not upload data to GitHub.

Controls: `kytp show`; `kytp export --output PRIVATE_FILE`; edit an exported copy and use `kytp replace --input FILE --confirm-replace`; `kytp forget --id ID --confirm-delete`; `kytp clear --confirm-delete`. Forget removes dependent guesses as well. Clear replaces Taste Memory with an empty document; it does not promise secure disk erasure, backup deletion, or removal of DSH/provider history. Uninstall removes runtime registrations, leaving the user's memory file until explicitly cleared.

Web text, Steam names and memory quotes are untrusted data. Prompt constraints prohibit obeying embedded instructions. Source checks prevent a web/tool result from being recorded directly as a human statement, but semantic interpretation still depends on the model: the plugin cannot guarantee jailbreak resistance, factual research quality, perfect natural-language correction, or medical-content filtering. Inspect memory and correct interpretations. Do not expose the profile as a shared endpoint, permit arbitrary third-party plugin code, or treat local file access as a security boundary against malicious local processes.
