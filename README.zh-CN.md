# Know Yourself Through Play

*成瘾让人忘记自己，真正契合的游戏却能让你认出自己。*  
*每款留在你心里的游戏，都恰好以最契合你天性的方式，回馈了你的行动。*

一个面向 **DeepSeek Harness** 的游戏发现与自我探索插件。  
它不为消磨时间，也不为把你困在黏性循环里。只需聊聊你玩过、喜欢或放弃的作品（也可按需导入已授权的 Steam 游戏库），它便通过**游戏回应行动的奖励机制**，帮你看清真正打动自己的原因，并找到下一款值得投入的作品。

## 为什么需要另一种推荐

大多数游戏推荐都在设法让你上瘾——用表层标签和惯性循环拴住你，尽可能拉长游玩时长。**我们不以“让你玩得更久”作为成功标准。**

决定一场游玩是消耗还是满足的，很少是表面有多像，而是**游戏的奖励机制如何回应你的行动**：

* **表面完全不同，奖赏却一致**  
  《星际拓荒》（宇宙探索）、《异星工厂》（工厂自动化）和《奥伯拉丁的回归》（推理）在类型和美术上几乎没有共同点，但它们奖赏的是同一件事：从未知中理出秩序，理解本身就是奖赏。
* **标签相同，体验却相反**  
  《蔚蓝》和《黑暗之魂》都带有“高难度”标签，体验却完全不同：《蔚蓝》让每一次瞬时重试都成为明确的进步；《黑暗之魂》则可能用漫长的跑图和高昂的死亡回退成本，很快消耗掉玩家的耐心。

**Know Yourself Through Play** 把游戏当作一面镜子：借你玩过的作品，映出你珍视的奖赏和排斥的阻力，再跳出既有的类型限制，寻找能带来真实满足感的游戏。

## 核心机制

* **以奖励机制为镜**  
  基于已发表的游戏心理学研究——包括自我决定理论（SDT）与玩家体验量表（PXI）——分析游戏如何奖赏行动，以及阻力从何而来。每一条洞察都是供你检验的**探索性假设**，而不是人格标签。
* **自然对话 + 可选 Steam 授权导入**  
  无需填写问卷。你可以直接用自然语言聊起玩过的作品，也可以按需连接明确授权的 Steam 游戏库作为起点。
* **奖赏匹配与排雷**  
  既按你偏爱的奖励机制跨类型寻找游戏，也提前标出可能打断体验的摩擦点，避开“看着合适、玩着疲惫”的作品。
* **可修改的品味记忆**  
  你的偏好记录与品味假设默认保存在本地，随每一次真实反馈持续修正。你始终拥有最终决定权——可以随时查看、反驳、修改或清空。
* **输入栏推荐开关**
  使用 **Web Search** 与 **Recent New Games** 两个按钮控制本 Session 的联网与新作筛选；默认都关闭，不再询问是否联网。

## 推荐模式

按钮位于 DSH Web／兼容桌面界面的现有聊天输入栏，选中时显示勾选标记与加粗样式。升级已有安装后请重启 DSH，让 Host 读取新增的客户端入口。

| Web Search | Recent New Games | 推荐方式 |
| --- | --- | --- |
| 关闭（默认） | 关闭（默认） | 仅用模型已有知识与 Taste Memory，禁止原生 Web Search／Web Fetch，不询问是否联网。 |
| 开启 | 关闭 | 允许原生联网工具，按动机与奖励机制寻找游戏，不限制发行时间。 |
| 开启 | 开启 | 优先发现近期正式发行的新游戏，核实名称、日期、发行状态与核心玩法，区分正式发行、Early Access 和未发行作品，结合 Taste Memory 推荐。 |

开启 **Recent New Games** 会自动开启 **Web Search**；取消前者不会关闭后者；关闭 **Web Search** 会同时关闭 **Recent New Games**。状态按 Session 隔离，保存在 Host 内存，不写入长期 Taste Memory；Host 重启或 Session 重新载入后默认关闭。按钮只在状态读取或更新时短暂禁用，不随模型生成过程锁定。

联网开关通过 DSH 原生 `tools.guard` 在工具执行前检查，覆盖注册名为 `web_search`、`web_fetch` 的调用；无 Session 身份时默认拒绝。关闭后阻止新开始的调用，已发出的网络请求不能撤回。这不是针对任意 shell、第三方插件或其他网络工具的全局网络防火墙。联网开启也需要实际可用的 DSH Web Provider；不可用时说明限制，不伪造搜索结果。近期与发行状态筛选由模型结合来源完成，不保证覆盖所有最新游戏。

TUI／无界面的 SDK 没有这两个按钮，默认使用模型已有知识；文字要求联网不会改变开关。

## 快速开始

> **早期 MVP 说明**：当前为面向 **DeepSeek Harness** 的早期原生插件。它直接复用 DSH 的模型、工具注册、联网检索与动态上下文能力，将自然语言探索与可选的 Steam 授权导入连接到同一份持久化的品味记忆中。

1. 在 **DeepSeek Harness** 中安装并启用本插件（配置见 `cordis.patch.yml` 与 `package.json`）。
2. 如需引入已授权的 Steam 游戏库上下文，请在 `.env` 中配置凭据（见 [隐私说明](./docs/privacy.md)）。
3. 跳过引导表单，直接开始对话即可。

### 试试这样问

需要联网的新作推荐时，先选中 **Recent New Games**（会自动开启 **Web Search**），再发送下方的新作示例。

* *“我喜欢《星际拓荒》和《异星工厂》，推荐几款类型完全不同、但奖励机制相似的游戏。”*
* *“为什么《蔚蓝》里一个难关我愿意试五十次，遇到高死亡惩罚或反复刷怪的游戏却会立刻失去耐心？”*
* *“最近想玩以观察和推理为核心、没有重复劳作的作品，顺便帮我标出潜在雷点。”*
* *“给我看看你现在对我游戏品味的猜想，有几条不准，我想改一改。”*
* *“我是游戏老玩家，经典作品大多熟悉。这次请联网检索近期新发布的游戏，按你记住的行动与奖励偏好推荐三款，核实发售时间，并标出潜在劝退点。”*

## 克制与边界

* **模型能力会影响效果。** 更擅长推理、理解细微反馈和可靠调用工具的模型，通常更适合这个 Harness；建议配置能力较强的模型，但不保证每次推断或推荐都准确。
* **假设，而非定论**：心理学视角只用于自我认识与选游参考，不构成心理测评、人格鉴定或医学诊断。你的真实感受始终高于一切推断。
* **你的记忆，由你掌控**：品味记忆默认保存在本地，Steam 授权范围与数据边界见 [隐私说明](./docs/privacy.md)。
* **诚实的能力边界**：作为早期 MVP，推荐覆盖范围取决于可用游戏资料、授权接口，以及 [研究说明](./docs/research.md) 和 [验证记录](./docs/validation.md) 中记录的验证范围。
